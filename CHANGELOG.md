# Changelog

## SR Client 0.22.0
First public release of SR Client, a native Krunker client for competitive
and custom lobbies.

- Native desktop client (Odin + OpenGL); the game does not run in a browser
- Join any custom or comp game by invite link; public matches are blocked
- Host comp games from inside SR with Krunker's Comp Server Setup options,
  in your Default Region
- Other players are drawn exactly where Krunker's server tests your shots
  (head, body, arms and legs follow Krunker's own hitboxes)
- Krunker updates are picked up at start-up; no new SR release needed
- Settings laid out like Krunker's, settings import from Krunker or Glorp,
  Krunker mods, chat, death cam, kill feed, hitmarkers (bars or an image),
  image crosshairs, cm/360 sensitivity
- After a game: the final scoreboard stays until Esc, then a fresh start
  screen; Refresh (F5) any time
- Krunker's 5-4-3-2-1 round countdown voice
